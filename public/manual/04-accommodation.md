# 第4章 配慮事項シートの書き方

このシートは、画面左の **「配慮事項シートを作成する」** を有効にしたときだけ作成・出力できます。
履歴書とは別の A4 1枚で、応募先に「働くうえで配慮してほしいこと」を伝えます。

> ★ **あなたが応募先に伝えたい範囲だけ** を PDF に出すことができます。
> 入力した内容が **すべて自動で出力されるわけではありません**。

## 4-1 機微情報トグルの考え方

配慮事項シートには **2 種類** のフィールドがあります。

### A. 機微情報（出すか出さないかをトグルで選ぶ）

| フィールド | 説明 | 既定 |
|---|---|---|
| 障害名・診断名 | 病名・診断名 | 出さない |
| 障害者手帳等 | 手帳の種類・等級 | 出さない |
| 通院状況 | 通院の頻度・時間 | 出さない |
| 服薬・体調管理 | 薬の内容や体調管理の方法 | 出さない |
| 相談先・連絡先 | 相談機関や担当者の連絡先など | 出さない |

> ⚠ **トグルを ON にした項目だけ** PDF に出ます。OFF のまま入力した内容は出ません。

### 機微情報の入力手順

▶ 手順：

1. 左メニューで **「配慮事項シート」** を選ぶ
2. 出力したい項目の **チェックボックスをON** にする（「○○を出力する」）
3. テキスト欄に内容を入力する
4. 画面右側の **仕上がり見本** で、入力した内容が配慮事項シートに反映されていることを確認する

> 💡 チェックボックスを ON にしないと、テキスト欄に入力しても PDF には出ません。「入力したのに出ない」と思ったら、まずチェックボックスを確認してください。

### B. 自分の状態を説明するフィールド（入力すれば必ず出る）

| フィールド | 書く内容の例 |
|---|---|
| 得意なこと・強み | 続けて取り組めること、得意な作業内容 |
| 苦手な環境・状況 | 苦手な音、光、人混みなど |
| お願いしたい配慮 | 休憩のとり方、指示の出し方の希望 |
| 自分で行っている工夫 | メモを取る、目覚ましをセットする等 |
| 体調悪化時のサイン | 周囲が気づくべき初期サイン |

### 自由記述の入力手順

▶ 手順：

1. 各テキスト欄に内容を入力する（チェックボックスはありません）
2. 入力した内容は **そのまま PDF に出力** されます
3. 空欄のままにした項目は PDF に表示されません

> 💡 書く内容に迷ったときは、このあとの「4-3 書き方の例」や [第8章の配慮事項テンプレ集](08-appendix.md) を参考にしてください。

### 書式設定（文字揃え）

配慮事項シートでも、各入力欄の文字を **左・中央・右** に揃えることができます。

▶ 手順：

1. セクション見出しの右側にある **「書式設定を表示」** ボタンを押す
2. 各入力欄の下に「左｜中央｜右」ボタンが表示される
3. 好みの位置を押す → PDF プレビューに即反映される

> 💡 通常はそのまま（左揃え）で問題ありません。

> 💡 学歴・職歴セクションでは、年・月や見出し行（「学歴」「職歴」）を **中央揃え**、「以上」を **右揃え** にするのがおすすめです。詳しくは [第3章「書式設定（文字揃え）」](03-input-guide.md) を参照してください。

## 4-2 出す／出さないの判断フロー

```
   応募先に伝えたい？
        │
   ┌────┴────┐
   │         │
  はい       いいえ
   │         │
   ▼         ▼
 トグルON  トグルOFF
（PDF出力） （入力しても出ない）
```

### 判断のヒント

| 場面 | 伝える？ |
|---|---|
| 面接で必ず聞かれる前提の応募（特例子会社など） | 多くの場合 ON |
| 応募先と初めて顔を合わせる前 | OFF にして、面接で口頭説明するのも選択肢 |
| 相談機関がすでに先方と連絡をとっている | 担当者と相談して決める |

> 💡 **迷ったら就職相談窓口へ相談**。応募先の文化によって慣行が異なります。

## 4-3 書き方の例（テンプレート）

> 巻末資料（[第8章](08-appendix.md)）に **障害種別ごとのテンプレ集** をまとめています。
> そのまま使うのではなく、自分の状況に合わせて言葉を直してから入力してください。

### 例：得意なこと・強み

- 「ルーチン化された作業を、決められた手順どおりに進めることが得意です。」
- 「数字や記録を扱う作業に集中して取り組めます。」

### 例：お願いしたい配慮

- 「指示は口頭だけでなく、メモやチャットなど文字で残していただけると助かります。」
- 「集中が必要な作業は午前中にまとめさせていただきたいです。」

### 例：体調悪化時のサイン

- 「2日連続で朝の挨拶が小声になっているときは、声をかけていただけると助かります。」

## 4-4 確認チェックリスト

PDF を出す前に確認します。

- [ ] 機微情報トグルが意図どおりに ON / OFF になっている
- [ ] 入力中の内容に **第三者の個人情報** が混ざっていない（家族・友人の氏名など）
- [ ] 文章は **応募先に読んで違和感がない** 言葉づかいになっている（必要なら信頼できる人と確認）
- [ ] 入力しただけで OFF のままの機微情報は **PDF に出ない** ことを確認した
