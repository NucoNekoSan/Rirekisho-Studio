# 第6章 入力データの保存・読込

## 6-1 なぜ保存が必要？

このツールは **サーバーには何も預けません**。
入力した内容は、明示的に有効化した場合だけ **この端末のブラウザ内** に自動保存できます。端末を移る場合やバックアップには **JSON ファイル** を使います。

> ★ 初期状態では、ブラウザを閉じると入力した内容は消えます。自分専用の端末では「この端末に保存する」を有効にできます。共用端末ではJSONファイルへ保存し、端末内保存は有効にしないでください。

### この端末に保存する

1. 左側の「この端末への保存」を確認する
2. 注意事項を読み、自分専用の端末であることを確認する
3. 「この端末に保存する」を有効にする
4. 書類名を付ける

有効にするとブラウザのIndexedDBへ自動保存され、複数の履歴書を作成・複製・削除できます。保存同意はいつでも解除でき、保存済み書類は個別または一括で削除できます。

## 6-2 入力データを保存する

▶ 手順：

1. 画面左メニューの「保存・PDF」を選ぶ
2. **入力データ保存** カードを見つける
3. 写真も一緒に残したいなら「写真も入力データに含める」にチェック（個人情報なので注意）
4. **入力データを保存** ボタンを押す
5. パソコンの「ダウンロード」フォルダに `.json` 拡張子のファイルが入る

> 💡 ファイル名はわかりやすく **「日付＋氏名」** にリネームしておくと、後で見つけやすいです。
> 例：`2026-06-30_佐藤花子.json`

### 写真を含めるかどうかの判断

| シチュエーション | 含める？ |
|---|---|
| 自分のパソコンに保存（USB含む） | 含めてもOK |
| クラウドや共有フォルダに置く | 慎重に。基本は含めない |
| メールで誰かに渡す | 含めない。写真は別途共有 |

> ⚠ JSON ファイル内では写真は **Base64 文字列** として保存されます。テキストエディタで開けば一応見えてしまうので、共有先を選んでください。

## 6-3 入力データを読み込む

別の日に続きから再開する手順。

▶ 手順：

1. Rirekisho StudioのURLを開く
2. 「保存・PDF」セクションへ移動
3. **入力データを読込** ボタンを押す
4. ファイル選択ダイアログで先ほどの `.json` を選ぶ
5. 入力欄に内容が戻る

> 💡 配慮事項シートを無効にして保存したJSONには、配慮事項の内容を含めません。

## 6-4 データ初期化（すべて消す）

別の人の履歴書を作りたいときや、デモデータを試したあとに使います。

▶ 手順：

1. 「保存・PDF」セクションの **データ初期化** カードを見つける
2. **入力をすべて消す** ボタンを押す
3. 確認メッセージが出るので **消去する** を押す

> ⚠ 初期化するまえに、必要なら入力データを **保存してから** 初期化してください。

## 6-5 安全な保管方法（例）

| 状況 | 推奨 |
|---|---|
| 入力途中のファイル | 自分だけが利用できるフォルダに保存 |
| 完成 PDF | 応募先ごとに分け、提出後も不要な複製を残さない |
| USBへ保存 | 紛失に注意し、写真を含める必要があるか確認する |
| クラウドへ保存 | 共有範囲とアカウントの安全性を確認する |
