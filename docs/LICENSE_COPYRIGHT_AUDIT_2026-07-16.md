# ライセンス・著作権監査 (2026-07-16)

## 結論

依存パッケージのライセンス情報は `package-lock.json` とインストール済みパッケージのメタデータで確認できる。一般公開準備としてMIT License、第三者通知、静的アセット台帳を追加し、出典を確認できなかった未使用SNSアイコン集を削除した。

## 確認済みの依存関係

直接依存の主なライセンスは次のとおり。

| パッケージ群 | ライセンス |
|---|---|
| React / React DOM、Vite、Vitest、jsPDF、html2canvas、Testing Library | MIT |
| Playwright、TypeScript、関連型定義の一部 | Apache-2.0 / MIT |
| その他の推移依存 | ISC、BSD-2-Clause、BSD-3-Clause、MPL-2.0、CC-BY-4.0、CC0-1.0、BlueOak-1.0.0 等 |

`package-lock.json` にはライセンス表記があるが、ライセンス表記だけでは配布時のNOTICE・帰属要件を満たした証拠にはならない。特に `caniuse-lite` (CC-BY-4.0)、MPL系、Apache系、BlueOak系は、実際に `dist` に含まれるコード・データと配布形態を確認して通知要否を確定する必要がある。

## リスク・未確認事項

### 高

- 解消済み: ルートにMIT `LICENSE`と`THIRD_PARTY_NOTICES.md`を追加した。
- 解消済み: 出典を確認できなかった未使用の`public/icons.svg`を削除した。
- `.git` に実質的な履歴がなく、アセットの作者・取得日時・許諾を履歴から立証できない。

### 中

- favicon、PWAアイコン、PNG/ICOが自作か生成物かは確認できるが、元素材の出典台帳がない。
- マニュアル・仕様書の文章はプロジェクト作成物と見られるが、外部文章の転載・引用元を検証できる記録がない。
- ビルド出力に第三者ライセンス表示が含まれるか、配布先でNOTICEを提供しているか未確認。

### 外部API

`src/lib/postalCode.ts` は ZipCloud API を利用する。API利用規約はAPI利用時の同意、禁止事項、ライセンス消滅条件を定めており、APIのみを提供する目的のサイトでの利用などを禁止している。[API利用規約](https://zipcloud.ibsnet.co.jp/rule/api)、[API仕様](https://zipcloud.ibsnet.co.jp/doc/api)

本アプリは履歴書作成機能の一部として住所検索を使っているため、現状の用途はAPI単独提供には該当しないと考えられる。ただし、規約変更・高頻度利用・商用公開時の扱いは公開前に再確認する。

## 対応要求

1. 依存関係更新時に`THIRD_PARTY_NOTICES.md`と配布物の通知要件を再確認する。
2. 新しい静的アセットを追加するときは`ASSET_PROVENANCE.md`へ由来を記録する。
3. ZipCloud APIの利用規約、公開ドメイン、想定トラフィックをリリース前に再確認する。
