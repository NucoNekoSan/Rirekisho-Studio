# ブラウザストレージポリシー

## 基本方針

初期状態はメモリのみで動作し、利用者が「この端末に保存する」を明示的に有効化した場合だけ、履歴書データをIndexedDBへ保存する。

## 保存先ごとの境界

### IndexedDB

利用者が端末保存へ同意した場合に限り、以下を保存できる：

- 履歴書の入力項目
- 住所、電話番号、メールアドレス、生年月日
- 写真データ
- 障害に関する情報
- 配慮事項シートの内容
- 作業メモ

共有端末では端末保存を有効にしないようUIで案内し、保存済み書類の個別削除と全削除を提供する。

### localStorage

端末保存への同意状態のような、個人情報を含まない設定だけを保存できる。履歴書本文、氏名、住所、連絡先、写真、配慮事項は保存してはならない。

### sessionStorage

使用しない。

### Cache API

Service Workerは静的アセットだけをキャッシュし、利用者が入力したデータをキャッシュしない。

## ガード

`src/lib/storageBoundary.test.ts` が、IndexedDBとlocalStorageの利用境界、およびsessionStorage不使用を自動検査する。
