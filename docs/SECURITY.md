# セキュリティ

## 保護対象

- 氏名、住所、電話番号、メールアドレス、生年月日
- 学歴・職歴および自由記述欄
- 写真
- 障害および配慮事項に関する情報

## ルール

- 履歴書本文、氏名、電話番号、写真、障害・配慮事項はサーバーへ送信しない。住所検索時だけ、正規化済みの7桁郵便番号をzipcloudへ送信する。
- localStorage、sessionStorageには履歴書の内容を保存しない。IndexedDBは利用者が端末保存へ明示同意した場合だけ使用する。
- 写真はデフォルトでJSON保存から除外する。
- 写真をJSON保存に含める場合は、UIで利用者に警告を表示する。
- 配慮事項シートを無効にしたJSON保存には、その内容を含めない。
- JSON読込時も包含フラグを検証し、無効な配慮事項と未包含の写真を状態へ取り込まない。
- JSON内の写真はメタデータだけでなくBase64の実サイズも上限以内か検証する。
- JSON内の写真はJPEGシグネチャも検証し、アップロードと読込でMIME・拡張子の受入条件を統一する。
- 配慮事項シートを有効にしたJSON保存にはその内容を含め、UIで利用者に警告を表示する。
- 追加書類を無効にしたPDF・Word・Excelには配慮事項シートの内容を含めない。
- 作業メモは印刷しない。
- 配備CSPはインラインスクリプト、外部フレーム、オブジェクト埋め込み、基底URL変更、外部フォーム送信を許可しない。
- PDF表示用として同一オリジンとBlobのフレームだけを許可する。

## 共有PC運用

- 「すべてクリア」ボタンを提供する。
- 必要なときだけダウンロードし、JSON/PDF/Word/Excelファイルの取り扱いに注意するよう利用者に案内する。

## 自動診断

- `npm run check:security` で危険API、秘密情報らしい値、CSP、source map、開発ファイルの配備混入を検査する。
- `npm run test:security` で本番相当ローカル環境の非破壊Chromium診断を実行する。
- `npm run security:sca` で開発依存込みと本番依存のみの既知脆弱性を監査する。
- 2026-07-16の診断結果と対象外項目は [セキュリティ診断レポート](SECURITY_ASSESSMENT_2026-07-16.md) に記録する。
