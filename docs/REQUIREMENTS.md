# REQUIREMENTS

## プロダクト目的

日本国内の利用者が、自分の端末で履歴書を入力し、A4/A3応募書類をPDF・Word・Excelで安全に作成できるようにする。

## 利用者

- 主利用者: 学生、転職者、再就職者を含む日本国内の求職者
- 補助者: 本人の入力・確認を手伝う家族、学校職員、支援者

## MVP成功条件

- A4縦またはA3横の履歴書PDFを表示・ダウンロードできる。
- PDFに近いA4縦またはA3横の履歴書様式を、編集可能なWord・Excelとしてダウンロードできる。学歴・職歴が枠を超える場合は続きページへ出力する。
- 必要な利用者はA4配慮事項シートを追加書類として有効化できる。
- 配慮事項シートの機微項目は本人が項目別ON/OFFで出力を選べる。
- JPG/JPEGの履歴書写真を取り込み、PDFへ反映できる。
- 入力データをJSONファイルとして保存・読込できる。
- サーバーへ個人情報を保存しない。端末保存は明示的な同意後だけ行う。

## Must

- React + TypeScript + Vite の静的SPA。
- Cloudflare Workers Static Assetsで `resume.nuconeko-garden.com` に公開する。
- IndexedDBで複数書類を管理し、schema v2 JSONを入出力できる。
- A4縦・A3横履歴書、A4配慮事項シートのPDF生成。
- ブラウザ内でWord・Excelを生成し、選択された配慮事項だけを含める。
- 写真上限は単一設定値から参照する。
- 初期状態では個人情報を永続保存せず、明示同意後だけ住所、電話、写真、配慮事項、履歴書本文をIndexedDBへ保存する。
- localStorageとsessionStorageには個人情報を保存しない。

## Won't in MVP

- 職務経歴書
- 添え状
- 支援員アカウントやレビューコメント
- サーバー保存、DB保存
- B4/B5等、A4縦・A3横以外の用紙バリエーション
