# 第2章 全体の流れ

履歴書ができあがるまでの **4ステップ** です。

```
 ┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐
 │ ステップ 1 │───▶│ ステップ 2 │───▶│ ステップ 3 │───▶│ ステップ 4 │
 │ 追加書類を │    │ 入力する   │    │ PDFを確認  │    │ 保存・印刷 │
 │ 確認する   │    │            │    │ する       │    │ する       │
 └────────────┘    └────────────┘    └────────────┘    └────────────┘
       ▲                  │                 │
       │                  ▼                 ▼
       └─── 途中で休む（入力データを保存）───┘
```

## ステップ 1 — 追加書類を確認する

画面左側の「追加書類」を確認します。通常の履歴書だけを作る場合は、初期状態のまま進みます。

| 選ぶもの | こんな人 |
|---|---|
| **チェックなし（初期状態）** | 通常の履歴書だけを作成 |
| **配慮事項シートを作成する** | 応募先へ配慮事項を別紙で伝える必要がある場合だけ有効化 |

> 💡 あとから切り替えても、入力した内容は消えません。

## ステップ 2 — 入力する

左側のメニューから順番にセクションを選んで入力します。

| セクション | だいたいの目安 |
|---|---|
| 基本情報 | 5〜10分 |
| 写真 | 2分 |
| 学歴・職歴 | 5〜15分 |
| 免許・資格 | 2〜5分 |
| 志望動機・希望 | 10〜30分 |
| 配慮事項（必要な場合のみ） | 15〜30分 |

> ★ **疲れたらいったん休んでOK** です。第6章で「入力データの保存」をやれば、後日続きから再開できます。

## ステップ 3 — PDFを確認する

画面の右側に「PDFプレビュー」があります。入力に合わせて即時に表示が変わります。

- 全体のレイアウトを見る → **全体表示** ボタン
- 文字をはっきり見る → **拡大表示** ボタン
- もっと大きく見る → **PDFを大きく確認** ボタン
- ブラウザで本物のPDFを開く → **履歴書PDFを表示** ボタン

## ステップ 4 — 保存・印刷する

- **履歴書PDFを保存** ボタンを押すと、パソコンの「ダウンロード」フォルダに PDF ファイルが入ります。
- 印刷するときは PDF を開いて、「印刷」を選びます（A4用紙・原寸大で印刷）。

> ⚠ 入力した内容を **後日も使いたい** ときは、PDFとは別に **入力データの保存**（第6章）も必ず行ってください。
