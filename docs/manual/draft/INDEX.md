## このマニュアルの対象

- 履歴書を **自分のペースで作りたい人**
- 一般的な履歴書を作成し、必要な場合だけ配慮事項シートを追加できます
- 家族、学校職員、支援者と一緒に画面を見ながら進めても構いません
