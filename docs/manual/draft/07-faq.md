# 第7章 よくある質問・トラブル対処

## Q1. 画面が真っ白で何も表示されない

- 一度ブラウザを閉じて、もう一度開いてみてください。
- それでも直らないときは、別のブラウザ（Chrome / Edge / Firefox）で開いてみてください。
- それでも直らないときは、ぬこねこの庭の問い合わせ窓口へ連絡してください。

## Q2. 郵便番号を入れても住所が出てこない

- 7桁の数字を入れた後、入力欄から離れる（Tab キー）必要があります。
- 存在しない郵便番号、または検索サービスのメンテナンス中の可能性があります。
- 住所は手で入力できます。

## Q3. 写真が縦長にならない

- 取り込んだ写真は **中央で 3:4（縦長）に自動切り抜き** されます。
- 顔がはじに寄っている写真は中央が空白になりがちです。スマホで顔が中央に来るように撮り直すと早いです。
- 「90度回転」ボタンで向きを直せます。

## Q4. PDF を表示しても何も出ない／真っ白

- 入力欄の **必須項目（氏名など）** が空のままだと、見えにくいことがあります。
- ブラウザのポップアップブロックが原因で新しいタブが開かないことがあります。「履歴書PDFを保存」を試してみてください。
- 大きな写真を使うと PDF 生成に時間がかかります。10秒ほど待ってから再度ボタンを押してみてください。

## Q5. PDF を保存できない／ダウンロードできない

- ブラウザのダウンロードフォルダが書き込めない場所になっている可能性があります。
- ブラウザの「ファイル名を毎回確認する」設定でキャンセルしてしまった可能性があります。再度ボタンを押してください。
- どうしても保存できないときは、画面に表示された PDF を右クリック → 「名前を付けて保存」でも保存できます。

## Q6. 学歴・職歴が 21 行以上に増えると、書いた行が見えなくなる

- A4 縦の場合、1ページ目は **21行まで固定**、2ページ目に続きが入ります。
- 2ページ目にも収まらない場合は、内容が切れたPDFを作らないため表示・保存ボタンが無効になります。内容を短くするか、**用紙形式を A3 横（1枚）に切り替えて**プレビューを確認します（第5章）。

## Q7. 「PDF出力前確認」で警告メッセージが出た

- 警告は **「このまま出力すると、これらの情報が PDF に入りますよ」** という確認です。
- 内容を読んで意図どおりであればそのまま出力してOK。意図と違うときは入力に戻ります。

## Q8. 配慮事項シートに書いたのに PDF に出ない

- **機微情報（5項目）はトグルが OFF だと出力されません。** 出したい項目はトグルを ON にしてください（第4章）。
- 機微情報ではない 5項目（得意なこと等）は、入力さえあれば自動で出ます。

## Q9. 「入力データを読込」を押したら、入力していた内容が消えた

- 読み込んだ JSON ファイルで **既存の入力が上書き** されます。
- 上書きしたくないときは、先に **入力データを保存** してから読込んでください。

## Q10. 文字の位置を変えたい（中央揃え・右揃えにしたい）

- 各セクションの見出し横にある **「書式設定を表示」** ボタンを押すと、入力欄ごとに **文字揃え（左・中央・右）** を選べるようになります。
- 変更は PDF に即反映されます。既定は左揃えです。
- 詳しくは第3章「書式設定（文字揃え）」を参照してください。

## Q11. 日本語が文字化けする／文字がくっついて見える

- ブラウザの設定で日本語フォントが入っていないと起きることがあります。
- 書体を「明朝」→「ゴシック」に切り替えて様子を見てください。
- 印刷時にも文字化けが残るなら、別のブラウザで開いてみてください。

## Q12. 同じ会社に何度も応募するので入力データを使い回したい

- JSON ファイルを保存しておけば、何度でも読み込めます。
- 志望動機だけ書き換えて再出力するワークフローが効率的です。

## Q13. 「配慮事項シートの出力項目: ◯件」と出ているけど合っている？

- これは **現在の入力で PDF に出る項目の数** を示しています。
- 数字が 0 のときは、全部のトグルが OFF、または入力が空の状態です。

## Q14. オフラインで使えますか？

- アプリをインストール済みなら、ネットにつながっていなくても使えます。
- 郵便番号の自動検索だけはネットが必要です。住所は手で入力できます。
- 詳しくは第1章「アプリをインストールする」を参照してください。

## Q15. インストールしたアプリを消したい

- アプリを開く → 右上の ⋮（メニュー） → 「アンインストール」

## Q16. 「新しいバージョンが利用可能です」と出た

- 「更新する」を押すと最新版に切り替わります。
- ⚠ 画面が再読み込みされるので、**入力途中のデータは先に保存**してください（第6章）。

## それでも解決しないとき

- 信頼できる人に画面を見せて相談してください。
- 入力データ（JSON）は個人情報を含むため、共有先と送信方法を十分に確認してください。
