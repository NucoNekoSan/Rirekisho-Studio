# 第8章 巻末資料

## 8-1 用語集（やさしい言い換え）

| ツール内の言葉 | 意味・言い換え |
|---|---|
| 追加書類 | 履歴書とは別に、必要な場合だけ作成する書類 |
| 配慮事項 | 働くうえでお願いしたいこと |
| 機微情報 | 取り扱いに気をつけたい個人情報（病名・診断・服薬など） |
| ふりがな | 名前の読み方を仮名で書いたもの |
| 西暦 / 和暦 | 2026年（西暦） / 令和8年（和暦） |
| 文字揃え | 文字を左・中央・右のどこに寄せるか |
| アライメント | 文字揃えと同じ意味 |
| JSON | 入力データを保存するファイル形式（中身は文字情報） |
| トグル | ON / OFF を切り替えるスイッチ |
| プレビュー | 仕上がりを画面で先に見ること |
| 用紙形式 | 紙の大きさと向き（A4縦／A3横） |
| ブラウザ | ホームページや Web ツールを表示するソフト（Chrome、Edge、Firefox など） |

## 8-3 配慮事項テンプレ集（参考）

> 💡 そのままコピーせず、自分の状況に合わせて言葉を直してから入力してください。

### 発達障害（ADHD/ASD）の方向け

**得意なこと・強み**
- 「決まった作業を、決められた手順で進めることが得意です。」
- 「数字や記録の正確さに気を配ることができます。」

**苦手な環境・状況**
- 「複数の人から同時に指示を受けると、優先順位がつけにくくなります。」
- 「予定が急に変わると、混乱しやすい傾向があります。」

**お願いしたい配慮**
- 「指示は口頭だけでなく、メモやチャットなど文字で残していただけると助かります。」
- 「タスクの優先順位を一度確認してから着手させてください。」

### 精神障害（うつ・統合失調症・双極性障害）の方向け

**苦手な環境・状況**
- 「人前で長時間話す場面は緊張が強く出ます。」
- 「短時間に多くの判断を求められると体調を崩しやすいです。」

**お願いしたい配慮**
- 「定期通院のため、月に1回半休をいただきたいです。」
- 「急な体調変化があった場合、休憩や早退を相談させてください。」

**体調悪化時のサイン**
- 「2日連続で挨拶が小声になっているときは、声をかけていただけると助かります。」

### 身体障害の方向け

**お願いしたい配慮**
- 「車椅子で移動するため、通路の幅と段差の有無を事前に共有してください。」
- 「キーボードのみで操作可能な作業を中心にお願いしたいです。」

### 高次脳機能障害の方向け

**自分で行っている工夫**
- 「予定はスマートフォンのリマインダーに必ず登録します。」
- 「業務手順をノートに書き出し、毎日始業時に確認します。」

**お願いしたい配慮**
- 「指示は文書で残していただけると、後から確認できて安心です。」

### 知的障害の方向け

**得意なこと・強み**
- 「ひとつずつ順番に作業することが得意です。」
- 「同じ手順を繰り返す仕事は集中して取り組めます。」

**お願いしたい配慮**
- 「指示はわかりやすい言葉でお願いしたいです。」
- 「困ったときに相談できる担当の方を決めていただけると助かります。」

## 8-4 相談しながら作成する場合の補足

### 利用者と並走するときのチェックポイント

- [ ] 配慮事項シートを付けるかどうかを **応募先と提出目的に合わせて確認** した
- [ ] 写真は **3か月以内** に撮影したもの
- [ ] 学歴・職歴の **時系列** に飛びがない
- [ ] 配慮事項シート：機微情報トグルの ON/OFF を本人と確認した
- [ ] 入力データ（JSON）を **自分の管理下** に保存してから画面を閉じた

### JSON ファイルの取り扱い

- 写真同梱版は **重要な個人情報** として、共有フォルダには置かない。
- 入力データは応募先別フォルダや日付を使って整理し、古い複製を増やしすぎない。
- 共用端末を使った場合は、ダウンロードしたファイルと端末内保存データを利用後に削除する。

### よくある運用課題

| 課題 | 対処 |
|---|---|
| PDF を保存し忘れる | 画面を閉じる前のチェック項目に追加 |
| 同じ JSON を複数人が同時編集 | 同時編集は不可。ファイル名に氏名と日付を入れる |
| 写真の差し替えで毎回苦戦する | あらかじめ 3:4 縦長で撮影したものをデスクトップに置く |
| 応募先ごとに志望動機を書き分けたい | 応募先名を入れた JSON ファイルを応募先ごとに保存する |

## 8-5 ツールの設計上の制限（参考）

| 項目 | 制限 |
|---|---|
| 写真ファイルサイズ | 10MB 以下 |
| 写真ファイル形式 | JPG / JPEG |
| 学歴・職歴 A4縦 上段 | 21行（固定） |
| 学歴・職歴 A4縦 下段 | 残りを表示（最低5行） |
| 免許・資格 | A4縦は入力行＋空行5行、A3横は入力行＋空行3行 |
| 学歴・職歴 A3横 左段 | 22行（固定） |
| 学歴・職歴 A3横 右段 | 残りを表示（最低7行） |
| 配慮事項シート | A4縦（必要に応じて複数ページ） |
| 機微情報フィールド | 5項目（個別にトグル制御） |
